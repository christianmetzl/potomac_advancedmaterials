# Claims ledger — every headline number, traced

**Purpose:** one table mapping every quantitative claim in the Phase 3 write-up to the script that
produces it, the committed evidence JSON, its `reproduce.py` check, and an honest status label. Nothing
in the paper is asserted without a traceable, rerunnable source. Status legend:

- **executed-CPU** — a real computation run on CPU; number recorded in the JSON.
- **circuit-sampled** — the genuine quantum pipeline (statevector sim + `qml.sample` shots), executed.
- **proxy** — determinant-space selected-CI proxy for circuit-sampled QSCI (no shots); hardware-independent.
  Validated against the circuit-sampled pipeline at 16q & 20q (see row "measured-vs-proxy").
- **fit** — an empirical fit on committed data points.
- **GPU-owed** — not yet executed; stated as a target, never as an achieved result. **No row currently
  carries this status**: the whole pre-registered campaign was executed on qBraid and the write-up contains
  no unfilled `[QBRAID-RUN]` placeholder. The one genuinely open item is *convergence* of the 40q
  `tensornet-mps` growth run (row 33 / E9), which is a sampling-strategy research question, not access.
- **Device sampling vs determinant space.** Where a row says GPU, read the evidence file: 20q/28q
  (`gpu_run1_h10/h14_nvidia`) and the AQT QPU rows are **device circuit-sampled** seeds followed by classical
  QSCI growth; the 40q flagship and the 38q CrO/Sn₂O₂ audits ran **in determinant space on a GPU host**
  (`peak_device_mem_gb: null`, `target: "qpp-cpu … no GPU/device sampling in this run"`). Their own JSONs say so.
- **No quantum advantage is claimed in any row.** No result here is faster than, or out of reach of, a
  classical method.
